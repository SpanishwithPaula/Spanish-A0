# Super Español · Made by: Maestra Paula

Sitio web interactivo A0 para niños lectores, con 25 misiones y cinco mundos. Diseño de estilo videojuego, actividades de vocabulario, opción de escuchar, retos y práctica oral. Almacena estrellas localmente en el navegador.

## Uso

Abre `index.html` en Chrome, Edge o Safari con conexión a internet. También puedes subir toda esta carpeta a un repositorio de GitHub y activar GitHub Pages (Deploy from a branch → main → root).

## Ilustraciones

**No se han generado imágenes con IA.** Las imágenes 2D son OpenMoji, servidas desde su CDN, bajo licencia CC BY-SA 4.0. Atribución visible en el pie de página, junto al enlace a la licencia. Web oficial: https://openmoji.org. Las ilustraciones requieren conexión a internet. Las palabras con traducción en inglés son una ayuda opcional al tocar o pasar sobre las tarjetas.

Los códigos de algunas imágenes pueden variar entre versiones de la biblioteca; en esos casos verás una imagen atenuada. La voz se selecciona automáticamente entre las voces de español disponibles, priorizando las que se identifican como naturales o neurales. La calidad depende del navegador y las voces disponibles; SpeechSynthesis no garantiza una voz humana. La aplicación no graba ni envía audio del estudiante.
